# wulffconsulting.no

Nettsiden til Wulff Consulting AS – organisasjonsdesign for mennesker og KI.

Hele siden ligger i `index.html`. Innhold som oppdateres ofte (nyheter, foredrag,
Medium-artikler og forskning) ligger samlet øverst i skriptet nederst i filen,
mellom `INNHOLD – rediger her` og `slutt på innhold`.

Publiseres med GitHub Pages fra `main`-grenen.
